# Food Twin Finder

Streamlit + SQLite 기반 학급 실시간 음식 취향 매칭 웹앱입니다.

## 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 교실에서 사용

1. 교사 탭에서 관리 비밀번호를 설정하고 6자리 학급 코드를 생성합니다.
2. 앱을 인터넷에서 접근 가능한 Streamlit 호스팅에 배포하고, 공개 주소를 QR 코드로 공유합니다.
3. 학생은 QR 접속 → 학급 코드/별명 입력 → 5문항 응답 → 결과 확인을 진행합니다.
4. 학생이 더 제출한 경우 `결과 새로고침`을 눌러 최신 매칭을 봅니다.
5. 교사는 학급 응답을 수업 종료 후 삭제합니다.

## 중요: 배포 환경

- SQLite는 **동일한 서버 인스턴스의 영속 디스크**를 전제로 합니다. Streamlit Community Cloud 등 재시작 시 로컬 파일이 사라질 수 있는 호스팅에서는 응답 데이터가 유실될 수 있습니다. 여러 인스턴스에서 구동하는 환경에도 적합하지 않습니다.
- 안정적인 실제 수업 운영에는 영속 DB(PostgreSQL/Supabase 등)로 교체하는 것을 권장합니다.
- 이 버전은 시연 및 단일 서버 소규모 수업용 MVP입니다. 별명 사칭 방지, 자동 새로고침, PIN 해시 저장, 제출 수정, 개인정보 보존 기간 자동화 등은 추가 개발이 필요합니다.
- 학생이 제출한 별명은 같은 반 다른 학생에게 노출됩니다. 실명은 사용하지 마세요.
